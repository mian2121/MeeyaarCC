# Awesome DESIGN.md

Catalog from [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md) (MIT). Each file is an inspired reading of a public site, not that brand's own design system.

## Instructions

1. Match the requested brand to a folder under `design-md/`.
2. Read that folder's `DESIGN.md` before writing UI.
3. Follow its theme, colors, type, components, layout, depth, responsive rules, and do's and don'ts.
4. Leave the catalog file in place. Copy it to the project root only if the user asks.
5. If the brand is not in the catalog, say so. Do not invent tokens for it.

Folder names that differ from the brand: `cal` (Cal.com), `linear.app` (Linear), `mistral.ai` (Mistral), `opencode.ai` (OpenCode), `runwayml` (Runway), `together.ai` (Together AI), `x.ai` (xAI). Every other folder name is the brand slug.
